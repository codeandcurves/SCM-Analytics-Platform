# 🚀 SCM Analytics Platform

## 📊 Project Overview
End-to-End Supply Chain Management Analytics Platform 
built using Python, Power BI, Power Automate & Machine Learning.

## 🛠️ Tools Used
- **Python** - Data Generation & ML Forecasting
- **Power BI** - Interactive Dashboards
- **Power Automate** - Automated Alerts
- **Machine Learning** - Demand Forecasting
- **GitHub** - Version Control

## 📁 Project Structure
- data_generation/ - Python scripts
- data/ - Generated CSV files
- powerbi/ - Power BI dashboard

## 📈 Dashboard Pages
1. Executive Overview
2. Inventory Analysis
3. Supplier & Procurement
4. Logistics & Shipments
5. Production Analysis
6. Demand Forecast

## 🤖 ML Model
- Algorithm: Linear Regression
- Purpose: 6 month demand forecasting
- MAE: 36.43 units
